More sources (optional)
Adzuna and Jooble are legitimate job-search APIs that need a free key you get yourself — I won't create accounts for you. Adding one meaningfully increases India coverage. Leave blank to skip.
How to get an Adzuna App ID & Key
  1. Open developer.adzuna.com and tap "Register".
  2. Sign up with your email — free, no card needed.
  3. After confirming your email and logging in, your App ID and App Key are shown on your account/dashboard page.
  4. Copy both into the fields below.
How to get a Jooble API Key
  1. Open jooble.org/api/about.
  2. Fill in the short request form — your name, email, and a one-line description of this app.
  3. Submit it — Jooble emails you an API key, usually within a day.
  4. Paste the key into the field below.
Company verification (optional, important)
No filter can guarantee a listing is 100% legitimate — treat this as help, not proof. With a free API key from OpenCorporates, the "Verify" button on each job card checks if the company is an actual registered business. Without a key, that same button opens a quick manual search instead — still useful, just not automatic.
How to get an OpenCorporates API Key
  1. Open opencorporates.com/api_accounts/new.
  2. Sign up for a free account (email + password, on their site — not this app).
  3. Once confirmed, go to your account page — your API token is listed there. Free tier has a limited monthly call quota, which is plenty for personal use.
  4. Copy the token into the field below.
